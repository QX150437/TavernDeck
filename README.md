### TavernDeck（酒馆总控台）功能介绍

1. **多入口与自定义外观**
   - **多端触发入口**：支持悬浮球（可拖拽、贴边自动缩小变淡、上传裁剪自定义图标）、酒馆顶部导航栏快捷图标（可自选嵌入位置）及左下角魔法棒拓展菜单。
   - **窗口与主题定制**：面板支持自由拖拽、缩放、自定义宽高及全屏模式；内置 5 套主题与悬浮球配色，支持自定义分组/条目文字颜色、按钮收纳策略及原生 Toast 通知提示。

2. **跨源分组总控与方案系统**
   - **多源条目聚合**：统一纳管酒馆**预设条目、世界书条目、酒馆脚本、正则条目**，支持控制台内直接开关、组内搜索、拖拽排序/嵌套子分组，以及条目正文与正则的快捷预览编辑（含撤销/重做）。
   - **单选与多选控制**：支持多选分组（支持一键全开/全关）与单选互斥分组；支持全局方案池管理及预设与方案的多对多绑定，切换预设自动切换对应方案。

3. **预设与世界书全功能管理**
   - **预设管理器**：支持预设新建、复制、重命名、删除、导入/导出及切换未保存提醒；支持主列表/未添加池条目增删改、批量选择移动、按序号搜索与跳转，以及生成参数全项可视化编辑。
   - **世界书管理器**：支持世界书新建、复制、重命名、删除、导入/导出；支持一键切换全局、角色卡（主/附加）及聊天世界书绑定；支持条目完整属性编辑、批量开关与一键禁止递归。

4. **版本对比与可视化缝合**
   - 支持**预设**及**世界书**跨版本自动匹配与差异分析（冲突/新增/删除）。
   - 提供行级与词元级高亮对比编辑，支持批量策略（仅迁移开关、全用旧/新版）与逐项/逐属性手动缝合（支持「只缝合内容」、同步滚动与撤销重做），结果可覆盖保存或另存为新预设/世界书。

5. **AI 智能批量编辑**
   - 可在预设或世界书详情中勾选多个条目并输入修改指令，调用当前 API（支持挂载破甲预设与覆盖模型名）批量生成修改方案，并以 Diff 形式检视确认后写回草稿。

6. **快照、备份与酒馆辅助**
   - **预设快照**：支持创建「开关状态快照」与「完整预设快照」，支持差异对比与恢复。
   - **数据备份与日志**：支持全量或局部（方案/快照/设置）JSON 导出及合并/覆盖导入；数据持久存于酒馆全局变量；内置运行日志捕获、筛选与导出。
   - **原生界面优化**：支持一键折叠酒馆原生预设设定区域（保留预设条目列表，支持随时点击原样展开）。
